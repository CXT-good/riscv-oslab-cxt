# 实验四：中断处理与时钟管理

### 任务1：理解RISC-V中断架构

#### 1. 中断特权级委托

**为什么需要中断委托？**

**目的**：减少特权级切换开销，提高系统效率

在RISC-V中：

**M模式**（Machine Mode）：最高特权级，直接访问所有硬件

**S模式**（Supervisor Mode）：操作系统运行的特权级

如果没有委托：
```
时钟中断 → M模式处理 → 调用S模式函数 → 返回M模式 → 返回用户程序
```
**开销**：需要两次特权级切换

有委托后：
```
时钟中断 → S模式直接处理 → 返回用户程序  
```
**优势**：减少一次M模式切换，提高性能

**关键委托寄存器**

**medeleg (Machine Exception Delegation)**

```c
// 异常委托位定义
#define DELEG_SYSCALL        (1 << 8)   // 环境调用（系统调用）
#define DELEG_PAGE_FAULT     (1 << 12)  // 指令页故障
#define DELEG_LOAD_PAGE_FAULT (1 << 13) // 加载页故障  
#define DELEG_STORE_PAGE_FAULT (1 << 15) // 存储页故障
```

**mideleg (Machine Interrupt Delegation)**  

```c
// 中断委托位定义
#define DELEG_SOFTWARE       (1 << 1)   // 软件中断（S模式）
#define DELEG_TIMER          (1 << 5)   // 定时器中断（S模式）
#define DELEG_EXTERNAL       (1 << 9)   // 外部中断
```

**哪些中断应该委托给S模式？**

**应该委托的**：**定时器中断**（Timer Interrupt）：任务调度、超时处理；**软件中断**（Software Interrupt）：核间通信、IPI；**页故障异常**：虚拟内存管理；**系统调用异常**：用户态到内核态的接口

**通常保留在M模式的**：严重硬件错误；平台特定设备中断；安全相关的异常。

#### 深入思考问题

##### 问题1：时钟中断为什么在M模式产生，却在S模式处理？

**根本原因**：硬件设计分离

1. **硬件层面**：
   
   时钟硬件直接连接到M模式
   
   M模式负责最基础的硬件管理
   
   这是RISC-V架构的安全设计
   
2. **软件层面**：
   
   操作系统运行在S模式
   
   调度器、定时器等OS组件需要时钟中断
   
   通过委托机制实现高效处理
   
3. **实际流程**：
   
   ```
   硬件时钟 → M模式检测 → 委托给S模式 → OS调度器处理
   ```
   
4. **优势**：
   
   **安全性**：M模式可以监控所有中断
   
   **灵活性**：OS可以选择处理哪些中断
   
   **性能**：通过委托减少特权级切换

##### 问题2：如何理解"中断是异步的，异常是同步的"？

**中断（Asynchronous - 异步）**

特征：与当前指令执行无关；随时可能发生；通常由**外部事件**触发。

例子：定时器中断：时间到了就触发；磁盘I/O完成中断；网络包到达中断。

处理：完成当前指令后响应。

**异常（Synchronous - 同步）**  

特征：由当前执行的指令直接导致；**可预测**的发生时机；指令执行的一部分

例子：页故障：访问未映射的地址；非法指令：执行未知操作码；除零异常：数学运算错误；系统调用：执行ecall指令。

处理：在当前指令执行过程中处理。

**关键区别**

| 特征     | 中断           | 异常             |
| -------- | -------------- | ---------------- |
| 触发源   | 外部设备       | 当前指令         |
| 时序     | 异步，不可预测 | 同步，可预测     |
| 返回地址 | 下一条指令     | 当前指令或下一条 |
| 处理目的 | 响应外部事件   | 处理指令错误     |



### 任务2：分析xv6的中断处理流程

#### 1. start.c 中的机器模式设置分析

##### 为什么时钟中断需要特殊处理？

```c
// start.c 中的关键代码
w_mideleg(r_mideleg() | (1L << 5));  // 委托时钟中断给S模式
w_mie(r_mie() | MIE_STIE);           // 使能S模式时钟中断
w_stimecmp(r_time() + 1000000);      // 设置下次中断时间
```

**特殊原因**：

1. 硬件依赖：时钟比较寄存器(`stimecmp`)只能在M模式访问。
2. 跨特权级协作：M模式：设置硬件定时器；S模式：处理定时器中断，实现调度。
3. 性能关键：时钟中断频率高，需要高效处理。

##### timervec 的作用

（1）保存M模式上下文

（2）清除定时器中断挂起位

（3）设置下次中断时间

（4）触发S模式软件中断（通过设置sip.SSIP）

（5）恢复上下文并返回

#### 2. kernelvec.S 的上下文切换分析

##### 寄存器保存策略

**保存的寄存器**（在kernelvec.S中）：

```assembly
sd ra, 0(sp)    # 返回地址
sd gp, 16(sp)   # 全局指针  
sd tp, 24(sp)   # 线程指针
sd t0, 32(sp)   # 临时寄存器
sd t1, 40(sp)
sd t2, 48(sp)
# ... 保存a0-a7参数寄存器
sd t3, 216(sp)  # 更多临时寄存器
sd t4, 224(sp)
sd t5, 232(sp)
sd t6, 240(sp)
```

**未保存的寄存器**：
- `sp`：栈指针（通过调整sp隐式保存）
- `s0-s11`：保存寄存器（由被调用者保存）
- CSR寄存器：单独处理

##### 为什么不保存所有寄存器？

基于**RISC-V调用约定**：

1. **调用者保存寄存器**（必须保存）：
   
   `ra`, `t0-t6`, `a0-a7`

   这些寄存器可能在函数调用中被修改
   
2. **被调用者保存寄存器**（不需要在中断入口保存）：
   
   `s0-s11`, `sp`, `gp`, `tp`

   被调用函数负责保存和恢复
   
3. **CSR寄存器**：
   
   `sepc`, `sstatus`, `scause`等
   
   通过特殊指令单独处理

##### 栈的使用策略

```c
// 栈帧布局（256字节）
struct kernel_stack_frame {
    uint64_t registers[32];  // 寄存器保存区
    // ... 其他上下文信息
};
```

**策略**：

**固定大小栈帧**：256字节，确保对齐

**内核栈专用**：每个CPU有自己的内核栈

**无动态分配**：避免在中断处理中分配内存

#### 3. trap.c 的中断分发机制

##### kerneltrap() 的核心逻辑

```c
void kerneltrap()
{
    // 1. 保存关键CSR寄存器
    uint64_t sepc = r_sepc();
    uint64_t sstatus = r_sstatus(); 
    uint64_t scause = r_scause();
    
    // 2. 安全检查
    if((sstatus & SSTATUS_SPP) == 0)
        panic("kerneltrap: not from supervisor mode");
    if(intr_get() != 0)
        panic("kerneltrap: interrupts enabled");

    // 3. 中断源识别和处理
    if((which_dev = devintr()) == 0){
        // 未知中断/异常
        printf("scause=0x%lx sepc=0x%lx\n", scause, r_sepc());
        panic("kerneltrap");
    }

    // 4. 特定处理（如调度）
    if(which_dev == 2 && myproc() != 0)  // 定时器中断
        yield();

    // 5. 恢复上下文
    w_sepc(sepc);
    w_sstatus(sstatus);
}
```

**中断源识别 - devintr()**

```c
int devintr()
{
    uint64_t scause = r_scause();
    
    if(scause == 0x8000000000000009L){
        // 外部设备中断（通过PLIC）
        return handle_external_interrupt();
    } else if(scause == 0x8000000000000005L){
        // 定时器中断
        clockintr();
        return 2;
    } else {
        return 0;  // 未知中断
    }
}
```

**scause 最高位解释**：

`1`：中断（Interrupt）

`0`：异常（Exception）

#### 关键问题深入分析

##### 问题1：中断处理中的重入问题如何解决？

**重入问题**：中断处理过程中又被更高优先级中断打断

**xv6的解决方案**：

1. **中断屏蔽**：
```c
// 进入kerneltrap时检查
if(intr_get() != 0)
    panic("kerneltrap: interrupts enabled");
// 说明在进入时中断应该已经被关闭
```

2. **分层处理**：
   
   **第一层**：`kernelvec.S` - 纯汇编，快速保存上下文
   
   **第二层**：`kerneltrap()` - C代码，实际处理
   
   **关键操作**在汇编层完成，避免重入
   
3. **栈隔离**：
   
   每个CPU有独立内核栈

   中断使用当前内核栈，不嵌套
   
4. **状态管理**：
```c
// 在usertrap中明确控制
intr_on();   // 只在安全时开启中断
intr_off();  // 关键操作前关闭中断
```

##### 问题2：中断处理时间过长会有什么后果？

**严重后果**：

1. **系统响应延迟**：其他中断无法及时处理；实时任务错过截止时间。
   
2. **数据丢失**：高速设备（如网络）缓冲区溢出；输入事件丢失。
   
3. **看门狗超时**：硬件看门狗复位系统。
   
4. **调度失衡**：时钟中断被阻塞，无法调度；进程饥饿。

**xv6的应对策略**：

1. **最小化中断处理**：
```c
void clockintr()
{
    // 只做最必要的操作
    ticks++;
    w_stimecmp(r_time() + 1000000);  // 快速设置下次中断
    // 复杂操作（如唤醒进程）在非中断上下文处理
}
```

2. **中断延迟处理**：设置标志位；在进程上下文处理实际工作。
   
3. **优先级区分**：时钟中断最高优先级；设备中断可适当延迟。

```c
// 中断原因定义
```

#### 2. 中断处理函数接口实现

**核心框架实现**

```c
// trap.c
#include "trap.h"
#include "printf.h"
#include "clock.h"
#include "sbi.h"

#define MAX_IRQ_NUM     16
#define IRQ_TIMER       5
#define IRQ_EXTERNAL    9

// 全局中断描述符表
static struct irq_desc irq_table[MAX_IRQ_NUM];
static int interrupts_enabled = 0;

// 中断统计
static uint64_t total_interrupts = 0;
static uint64_t total_exceptions = 0;

// 初始化中断系统
void trap_init(void)
{
    printf("TRAP: Initializing interrupt system...\n");
    
    // 清零中断描述符表
    for (int i = 0; i < MAX_IRQ_NUM; i++) {
        irq_table[i].handler = NULL;
        irq_table[i].name[0] = '\0';
        irq_table[i].count = 0;
        irq_table[i].enabled = 0;
        irq_table[i].shared = 0;
        irq_table[i].priority = 0;
    }
    
    // 注册默认中断处理函数
    register_interrupt(IRQ_TIMER, handle_timer_interrupt, "timer", 7);
    register_interrupt(IRQ_EXTERNAL, handle_external_interrupt, "external", 5);
    
    // 设置中断向量
    extern void kernel_vector(void);
    asm volatile("csrw stvec, %0" : : "r"((uint64_t)kernel_vector));
    
    // 启用中断
    asm volatile("csrs sie, %0" : : "r"((uint64_t)(1 << IRQ_TIMER | 1 << IRQ_EXTERNAL)));
    
    interrupts_enabled = 1;
    printf("TRAP: Interrupt system initialized\n");
}

// 注册中断处理函数
void register_interrupt(int irq, interrupt_handler_t handler, const char *name, uint8_t priority)
{
    if (irq < 0 || irq >= MAX_IRQ_NUM) {
        printf("TRAP: Invalid IRQ number %d\n", irq);
        return;
    }
    
    if (irq_table[irq].handler != NULL && !irq_table[irq].shared) {
        printf("TRAP: IRQ %d already registered (%s)\n", irq, irq_table[irq].name);
        return;
    }
    
    irq_table[irq].handler = handler;
    if (name) {
        strncpy(irq_table[irq].name, name, sizeof(irq_table[irq].name) - 1);
    }
    irq_table[irq].priority = priority & 0x7; // 3-bit priority
    irq_table[irq].enabled = 1;
    
    printf("TRAP: Registered IRQ %d: %s (priority %d)\n", irq, name, priority);
}

// 注销中断处理函数
void unregister_interrupt(int irq)
{
    if (irq < 0 || irq >= MAX_IRQ_NUM) {
        return;
    }
    
    printf("TRAP: Unregistering IRQ %d: %s\n", irq, irq_table[irq].name);
    
    irq_table[irq].handler = NULL;
    irq_table[irq].name[0] = '\0';
    irq_table[irq].enabled = 0;
}

// 启用特定中断
void enable_interrupt(int irq)
{
    if (irq < 0 || irq >= MAX_IRQ_NUM) {
        return;
    }
    
    irq_table[irq].enabled = 1;
    uint64_t mask = (1UL << irq);
    asm volatile("csrs sie, %0" : : "r"(mask));
    
    printf("TRAP: Enabled IRQ %d\n", irq);
}

// 关闭特定中断
void disable_interrupt(int irq)
{
    if (irq < 0 || irq >= MAX_IRQ_NUM) {
        return;
    }
    
    irq_table[irq].enabled = 0;
    uint64_t mask = (1UL << irq);
    asm volatile("csrc sie, %0" : : "r"(mask));
    
    printf("TRAP: Disabled IRQ %d\n", irq);
}

// 全局启用中断
void enable_interrupts(void)
{
    asm volatile("csrs sstatus, %0" : : "r"(1UL << 1)); // SIE bit
    interrupts_enabled = 1;
}

// 全局关闭中断
void disable_interrupts(void)
{
    asm volatile("csrc sstatus, %0" : : "r"(1UL << 1)); // SIE bit
    interrupts_enabled = 0;
}
```

#### 3. 中断处理核心逻辑

```c
// 主中断处理函数
void handle_interrupt(struct trapframe *tf)
{
    uint64_t cause = tf->scause;
    int is_interrupt = (cause & CAUSE_INTERRUPT) != 0;
    
    if (is_interrupt) {
        total_interrupts++;
        uint64_t irq = cause & ~CAUSE_INTERRUPT;
        
        // 查找并调用中断处理函数
        if (irq < MAX_IRQ_NUM && irq_table[irq].handler && irq_table[irq].enabled) {
            irq_table[irq].count++;
            irq_table[irq].handler(cause, tf->sepc, tf->stval);
        } else {
            printf("TRAP: Unhandled interrupt: cause=0x%lx, epc=0x%lx\n", 
                   cause, tf->sepc);
        }
    } else {
        // 异常处理
        total_exceptions++;
        handle_exception(cause, tf->sepc, tf->stval);
    }
}

// 定时器中断处理
void handle_timer_interrupt(uint64_t cause, uint64_t epc, uint64_t tval)
{
    static uint64_t tick_count = 0;
    tick_count++;
    
    // 设置下一次定时器中断
    sbi_set_timer(get_cycles() + 1000000); // 1ms间隔
    
    // 简单的定时任务：每100个tick打印一次
    if (tick_count % 100 == 0) {
        printf("TIMER: Tick %lu, total interrupts: %lu\n",
```

#### 3. 栈管理实现

**栈分配和溢出检测**

```c
// stack.c - 栈管理
#include "trap.h"
#include "printf.h"

#define KERNEL_STACK_SIZE  4096
#define STACK_GUARD_SIZE   128

// 每个CPU的内核栈
typedef struct {
    uint8_t stack[KERNEL_STACK_SIZE];
    uint8_t guard[STACK_GUARD_SIZE];  // 栈保护区域
    uint32_t magic;
} kernel_stack_t;

// CPU数量（假设单核）
static kernel_stack_t kernel_stacks[1] = {0};
static uint64_t current_stack_usage = 0;
static uint64_t max_stack_usage = 0;

// 栈初始化
void stack_init(int cpuid)
{
    if (cpuid >= 1) return;
    
    kernel_stack_t *stack = &kernel_stacks[cpuid];
    
    // 设置栈保护区域为特定模式
    for (int i = 0; i < STACK_GUARD_SIZE; i++) {
        stack->guard[i] = 0xAA;
    }
    
    stack->magic = STACK_MAGIC;
    
    printf("STACK: Kernel stack initialized for CPU %d at %p\n", 
           cpuid, stack->stack + KERNEL_STACK_SIZE);
}

// 栈溢出检测
int check_stack_overflow(struct trapframe *tf)
{
    uint64_t current_sp = (uint64_t)tf->original_sp;
    kernel_stack_t *stack = &kernel_stacks[0];  // 假设CPU 0
    
    uint64_t stack_top = (uint64_t)stack->stack + KERNEL_STACK_SIZE;
    uint64_t stack_bottom = (uint64_t)stack->stack;
    
    // 检查栈指针是否在有效范围内
    if (current_sp < stack_bottom || current_sp >= stack_top) {
        printf("STACK: Stack pointer out of bounds: %p\n", (void*)current_sp);
        return -1;
    }
    
    // 检查栈保护区域
    for (int i = 0; i < STACK_GUARD_SIZE; i++) {
        if (stack->guard[i] != 0xAA) {
            printf("STACK: Stack overflow detected! Guard corrupted at %d\n", i);
            return -1;
        }
    }
    
    // 计算栈使用量
    uint64_t usage = stack_top - current_sp;
    if (usage > max_stack_usage) {
        max_stack_usage = usage;
    }
    current_stack_usage = usage;
    
    return 0;
}

// 栈使用统计
void stack_stats(void)
{
    printf("STACK: Current usage: %lu bytes, Max usage: %lu bytes\n",
           current_stack_usage, max_stack_usage);
    printf("STACK: Available: %lu bytes\n", 
           KERNEL_STACK_SIZE - current_stack_usage);
}
```

**多级中断栈管理**

```c
// 嵌套中断管理
struct nested_interrupt {
    int level;
    struct trapframe *frames[8];  // 支持最多8级嵌套
    uint64_t saved_sstatus[8];
};

static struct nested_interrupt nest_info = {0};

// 进入中断处理
void enter_interrupt(struct trapframe *tf)
{
    if (nest_info.level >= 8) {
        printf("TRAP: Interrupt nesting too deep (%d), system halted\n", 
               nest_info.level);
        while (1) asm volatile("wfi");
    }
    
    // 保存当前中断状态
    nest_info.frames[nest_info.level] = tf;
    nest_info.saved_sstatus[nest_info.level] = tf->sstatus;
    
    nest_info.level++;
    
    // 如果是第一级中断，禁用进一步中断
    if (nest_info.level == 1) {
        asm volatile("csrc sstatus, %0" : : "r"(1UL << 1)); // 清除SIE
    }
}
```

```c
// 定时器子系统初始化
void timer_subsystem_init(void)
{

        callbacks[i].func = NULL;

// 注册定时器回调
int timer_register_callback(void (*func)(void), uint64_t interval_ns, const char *name)
{
    if (callback_count >= MAX_TIMER_CALLBACKS) {
        printf("TIMER: Cannot register callback, maximum reached\n");
        return -1;
    }
    
    if (func == NULL) {
        printf("TIMER: Invalid callback function\n");
        return -1;
    }
    
    int id = -1;
    for (int i = 0; i < MAX_TIMER_CALLBACKS; i++) {
        if (callbacks[i].func == NULL) {
            id = i;
            break;
        }
    }
    
    if (id == -1) {
        printf("TIMER: No free callback slot\n");
        return -1;
    }
    
    callbacks[id].func = func;
    callbacks[id].interval_ns = interval_ns;
    callbacks[id].last_call_ns = get_system_time_ns();
    callbacks[id].enabled = 1;
    
    if (name) {
        strncpy(callbacks[id].name, name, sizeof(callbacks[id].name) - 1);
    } else {
        snprintf(callbacks[id].name, sizeof(callbacks[id].name), "timer_%d", id);
    }
    
    callback_count++;
    printf("TIMER: Registered callback '%s' (interval: %lu ns)\n", 
           callbacks[id].name, interval_ns);
    
    return id;
}

// 注销定时器回调
void timer_unregister_callback(int id)
{
    if (id < 0 || id >= MAX_TIMER_CALLBACKS || callbacks[id].func == NULL) {
        return;
    }
    
    printf("TIMER: Unregistered callback '%s'\n", callbacks[id].name);
    
    callbacks[id].func = NULL;
    callbacks[id].enabled = 0;
    callbacks[id].name[0] = '\0';
    callback_count--;
}

// 处理定时器回调
void timer_process_callbacks(void)
{
    uint64_t current_time = get_system_time_ns();
    
    for (int i = 0; i < MAX_TIMER_CALLBACKS; i++) {
        if (callbacks[i].func && callbacks[i].enabled) {
            uint64_t elapsed = current_time - callbacks[i].last_call_ns;
            
            if (elapsed >= callbacks[i].interval_ns) {
                // 执行回调
                callbacks[i].func();
                callbacks[i].last_call_ns = current_time;
            }
        }
    }
}
```

```c
{
    uint64_t current_cycle = sbi_get_time();

    stats.total_interrupts++;

        uint64_t interval = current_cycle - stats.last_cycle;

        }

    // 处理定时器回调
    timer_process_callbacks();
    
    // === 触发任务调度 ===
    if (scheduler_ready && (stats.total_interrupts % schedule_interval_ticks == 0)) {
        schedule();

    // 设置下一次时钟中断
    sbi_set_timer(current_cycle + 1000000); // 1ms后再次中断
```

```c
// scheduler.c  
#include "scheduler.h"
#include "printf.h"
#include "clock.h"

#define MAX_PROCESSES    8
#define TIME_SLICE       5     // 每个进程的时间片（tick数）

static struct process proc_table[MAX_PROCESSES];
static int current_pid = -1;
static int process_count = 0;
static uint64_t schedule_count = 0;

// 简单的轮转调度器初始化
void scheduler_init(void)
{
    for (int i = 0; i < MAX_PROCESSES; i++) {
        proc_table[i].pid = -1;
        proc_table[i].state = PROC_UNUSED;
        proc_table[i].counter = 0;
        proc_table[i].priority = 1;
        proc_table[i].runtime = 0;
        proc_table[i].name[0] = '\0';
    }
    
    process_count = 0;
    current_pid = -1;
    
    printf("SCHED: Scheduler initialized (RR, time slice: %d ticks)\n", TIME_SLICE);
}

// 创建进程
int create_process(const char *name, uint64_t priority)
{
    if (process_count >= MAX_PROCESSES) {
        printf("SCHED: Cannot create process, table full\n");
        return -1;
    }
    
    int pid = -1;
    for (int i = 0; i < MAX_PROCESSES; i++) {
        if (proc_table[i].state == PROC_UNUSED) {
            pid = i;
            break;
        }
    }
    
    if (pid == -1) {
        printf("SCHED: No free process slot\n");
        return -1;
    }
    
    proc_table[pid].pid = pid;
    proc_table[pid].state = PROC_RUNNABLE;
    proc_table[pid].counter = TIME_SLICE;
    proc_table[pid].priority = priority;
    proc_table[pid].runtime = 0;
    
    if (name) {
        strncpy(proc_table[pid].name, name, sizeof(proc_table[pid].name) - 1);
    } else {
        snprintf(proc_table[pid].name, sizeof(proc_table[pid].name), "process_%d", pid);
    }
    
    process_count++;
    printf("SCHED: Created process %d: %s (priority: %lu)\n", pid, proc_table[pid].name, priority);
    
    return pid;
}

// 退出进程
void exit_process(int pid)
{
    if (pid < 0 || pid >= MAX_PROCESSES || proc_table[pid].state == PROC_UNUSED) {
        return;
    }
    
    printf("SCHED: Process %d (%s) exited, runtime: %lu ticks\n",
           pid, proc_table[pid].name, proc_table[pid].runtime);
    
    proc_table[pid].state = PROC_UNUSED;
    proc_table[pid].pid = -1;
    proc_table[pid].name[0] = '\0';
    process_count--;
    
    if (current_pid == pid) {
        current_pid = -1;
    }
}

// === 核心调度函数 ===
void schedule(void)
{
    schedule_count++;
    
    // 如果没有进程，直接返回
    if (process_count == 0) {
        return;
    }
    
    // 查找下一个可运行的进程
    int next_pid = -1;
    
    // 简单的轮转调度算法
    for (int i = 1; i <= MAX_PROCESSES; i++) {
        int candidate = (current_pid + i) % MAX_PROCESSES;
        
        if (proc_table[candidate].state == PROC_RUNNABLE) {
            next_pid = candidate;
            break;
        }
    }
    
    if (next_pid == -1) {
        // 没有可运行的进程
        return;
    }
    
    // 执行上下文切换
    if (current_pid != next_pid) {
        // 保存当前进程上下文（实际系统中这里会保存寄存器等）
        if (current_pid != -1) {
            proc_table[current_pid].state = PROC_RUNNABLE;
        }
        
        // 切换到新进程
        current_pid = next_pid;
        proc_table[current_pid].state = PROC_RUNNING;
        proc_table[current_pid].counter = TIME_SLICE;
        
        printf("SCHED: [%lu] Switch: PID %d -> %d (%s)\n", 
               schedule_count, 
               (current_pid == -1) ? -1 : current_pid, 
               next_pid, proc_table[next_pid].name);
    }
    
    // 更新当前进程的运行时间
    if (current_pid != -1) {
        proc_table[current_pid].runtime++;
        proc_table[current_pid].counter--;
        
        // 时间片用完，标记为可重新调度
        if (proc_table[current_pid].counter <= 0) {
            proc_table[current_pid].counter = TIME_SLICE;
            // 在下次调度时会切换到其他进程
        }
    }
}

// 显示调度器状态
void scheduler_dump(void)
{
    printf("=== Scheduler Status ===\n");
    printf("Total schedules: %lu\n", schedule_count);
    printf("Active processes: %d/%d\n", process_count, MAX_PROCESSES);
    printf("Current PID: %d\n", current_pid);
    
    printf("Process table:\n");
    for (int i = 0; i < MAX_PROCESSES; i++) {
        if (proc_table[i].state != PROC_UNUSED) {
            const char *state_str = "UNKNOWN";
            switch (proc_table[i].state) {
                case PROC_RUNNABLE: state_str = "RUNNABLE"; break;
                case PROC_RUNNING: state_str = "RUNNING"; break;
                case PROC_SLEEPING: state_str = "SLEEPING"; break;
                case PROC_ZOMBIE: state_str = "ZOMBIE"; break;
            }
            
            printf("  PID %d: %s [%s] counter=%lu runtime=%lu\n",
                   proc_table[i].pid, proc_table[i].name, state_str,
                   proc_table[i].counter, proc_table[i].runtime);
        }
    }
}
```

#### 关键设计问题的解答

##### 1. 如何在时钟中断中触发调度？

**策略**：周期性触发 + 条件检查

```c
// 在时钟中断处理中
if (scheduler_ready && (stats.total_interrupts % schedule_interval_ticks == 0)) {
    schedule();  // 触发调度
}
```

##### 2. 调度的时机选择有什么考虑？

**考虑因素**：

**响应性**：太频繁会增加开销，太稀疏会降低响应速度

**公平性**：确保每个进程都能得到CPU时间

**开销**：调度本身有成本，需要平衡

**实时性**：对实时任务需要更频繁的调度

**当前方案**：每N个tick调度一次，可通过`set_schedule_interval()`调整

##### 3. 如何确保调度的原子性？

**原子性保证**：

1. **中断屏蔽**：在关键调度操作期间禁用中断
2. **数据结构保护**：使用锁或原子操作保护共享数据
3. **上下文保存**：完整保存和恢复寄存器状态
4. **状态一致性**：确保进程状态转换的原子性

```c
// 伪代码示例
void schedule(void)
{
    // 1. 禁用中断
    disable_interrupts();
    
    // 2. 保存当前上下文
    save_current_context();
    
    // 3. 选择下一个进程（关键区）
    next_pid = select_next_process();
    
    // 4. 切换上下文
    switch_context(current_pid, next_pid);
    
    // 5. 恢复中断
    enable_interrupts();
}
```

```c
void register_exception_handler(trap_cause_t cause, exception_handler_t handler, const char *name)
{
    if (handler_count >= MAX_EXCEPTION_HANDLERS) {
        printf("EXCEPTION: Cannot register handler, table full\n");
        return;
    }
    
    exc_handlers[handler_count].cause = cause;
    exc_handlers[handler_count].handler = handler;
    exc_handlers[handler_count].name = name;
    
    // 设置默认严重级别
    if (cause == EXC_BREAKPOINT) {
        exc_handlers[handler_count].level = EXC_LEVEL_DEBUG;
    } else if (cause >= EXC_INSTR_PAGE_FAULT && cause <= EXC_STORE_PAGE_FAULT) {
        exc_handlers[handler_count].level = EXC_LEVEL_RECOVERABLE;
    } else if (cause == EXC_ECALL_S_MODE) {
        exc_handlers[handler_count].level = EXC_LEVEL_KERNEL;
    } else {
        exc_handlers[handler_count].level = EXC_LEVEL_FATAL;
    }
    
    handler_count++;
    printf("EXCEPTION: Registered handler for %s (cause: %d)\n", name, cause);
}

// 主异常处理函数
void handle_exception(struct trapframe *tf)
{
    uint64_t cause = tf->scause;
    uint64_t epc = tf->sepc;
    uint64_t tval = tf->stval;
    
    // 更新统计
    exc_stats.total_exceptions++;
    if (cause < sizeof(exc_stats.by_cause)/sizeof(exc_stats.by_cause[0])) {
        exc_stats.by_cause[cause]++;
    }
    
    // 准备异常信息
    struct exception_info info = {
        .cause = cause,
        .epc = epc,
        .tval = tval,
        .level = EXC_LEVEL_FATAL,
        .description = "Unknown exception"
    };
    
    // 查找描述
    if (cause < sizeof(exception_descriptions)/sizeof(exception_descriptions[0]) && 
        exception_descriptions[cause] != NULL) {
        info.description = exception_descriptions[cause];
    }
    
    printf("\n=== EXCEPTION DETECTED ===\n");
    printf("Cause:  %d (%s)\n", cause, info.description);
    printf("EPC:    0x%016lx\n", epc);
    printf("TVAL:   0x%016lx\n", tval);
    printf("SSTATUS:0x%016lx\n", tf->sstatus);
    
    // 查找并调用处理程序
    int handled = 0;
    for (int i = 0; i < handler_count; i++) {
        if (exc_handlers[i].cause == cause && exc_handlers[i].handler != NULL) {
            info.level = exc_handlers[i].level;
            
            int result = exc_handlers[i].handler(tf, &info);
            if (result == 0) {
                // 处理成功
                exc_stats.recovered++;
                handled = 1;
                printf("EXCEPTION: Handled by %s, resuming execution\n", exc_handlers[i].name);
                break;
            } else {
                printf("EXCEPTION: Handler %s failed (code: %d)\n", exc_handlers[i].name, result);
            }
        }
    }
    
    if (!handled) {
        // 未处理的异常
        exc_stats.fatal++;
        printf("EXCEPTION: No handler found for cause %d\n", cause);
        panic("Unhandled exception", tf);
    }
}

    }
}
```

```
// 中断性能测试函数
void test_interrupt_overhead(void) {
    printf("\n=== Interrupt Overhead Measurement ===\n");
    
    // 保存初始时间
    uint64_t start_time, end_time;
    uint64_t total_cycles = 0;
    int test_iterations = 100;
    
    printf("Measuring interrupt handling overhead (%d iterations)...\n", test_iterations);
    
    // 测量多次中断处理的平均时间
    for (int i = 0; i < test_iterations; i++) {
        // 读取当前时间作为开始
        asm volatile("csrr %0, time" : "=r"(start_time));
        
        // 模拟一个简单的中断处理流程
        // 这里我们直接调用时钟中断处理来测量
        clock_set_next_event();
        
        // 读取结束时间
        asm volatile("csrr %0, time" : "=r"(end_time));
        
        total_cycles += (end_time - start_time);
        
        // 小延迟以避免测量偏差
        for (int j = 0; j < 100; j++) {
            asm volatile("nop");
        }
    }
    
    uint64_t avg_cycles = total_cycles / test_iterations;
    printf("Average interrupt handling overhead: %lu cycles\n", avg_cycles);
    
    // 测量上下文切换成本
    printf("\nMeasuring context switch cost...\n");
    
    total_cycles = 0;
    for (int i = 0; i < test_iterations; i++) {
        asm volatile("csrr %0, time" : "=r"(start_time));
        
        // 模拟上下文保存（简化版）
        asm volatile(
            "addi sp, sp, -16\n"
            "sd ra, 0(sp)\n"
            "sd a0, 8(sp)\n"
            :
            :
        );
        
        // 模拟上下文恢复
        asm volatile(
            "ld a0, 8(sp)\n"
            "ld ra, 0(sp)\n"
            "addi sp, sp, 16\n"
            :
            :
        );
        
        asm volatile("csrr %0, time" : "=r"(end_time));
        
        total_cycles += (end_time - start_time);
    }
    
    avg_cycles = total_cycles / test_iterations;
    printf("Average context switch cost: %lu cycles\n", avg_cycles);
    
    printf("=== Interrupt Overhead Analysis Completed ===\n\n");
}
```
